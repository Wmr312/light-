导光柱光迹模拟工具 · 软件使用说明

面向结构工程师的导光柱设计验证工具 — 工作区与多盘管理 · 导入 3D 模型 · LED 灯珠选型 · 光线追踪 · 光斑分析 · 一键报告

适用版本：v3.2 · 文档更新：2026-11-24

一、软件简介

导光柱光迹模拟工具（light-guide-validator）用于在开模 / 打样之前快速验证导光柱方案的出光效果。导入结构工程师建好的三维模型，选择材料与 LED 灯珠型号，程序用光线追踪（Möller–Trumbore 求交 + Beer-Lambert 吸收 + 能量账本）统计出射端与侧壁的能量分布，给出光斑、均匀性与达标结论，并可一键生成验证报告。

典型应用：仪表导光柱、指示灯导光件、按键背光、机箱 / 服务器面板导光等需要在指定区域均匀出光的透明零件。

两级管理模式：工作区（一个 .lgv.json 文件，对应一个开发人员 / 一个工程）→ 内含多个仿真盘（每次方案对比一块盘）。一个工作区里的多块盘会并排显示在同一个 3D 场景中，便于横向对比。

定位说明：本工具的几何来源统一为导入的三维模型。软件不再提供参数化建模示例，也不提供侧棱镜微齿等附加结构生成 —— 模型长什么样，仿真就按什么样计算，所见即所得。

二、快速上手（七步出结果）

  1. 进入 Home 启动页 — 新建一个工作区（或直接使用默认工作区）。工作区卡片顶部带 3D 预览图，可直接看到该工作区内的盘。
  2. 添加仿真盘 — 点卡片「打开」进入 3D 视图，用左上角「＋ 新建盘」增加一块空盘；每块盘独立保存自己的模型、材料、灯珠与仿真记录。
  3. 导入模型 — 进入「模型配置 → 文件导入」，选择 STL / OBJ / STEP 文件；同时设定 LED 与入光面之间的装配间隙。
  4. 选材料与灯珠 — 材料选型下拉选 PMMA / PC 等常用料；LED 灯珠选型库选封装型号（如 0603）、亮度档位，需要时可填 X / Y 偏移与旋转角。
  5. 设定端面 — 点「自动检测端面」，或用拾取按钮手动点选入射面 / 出射面（Shift + 点击可累加多个面）。清除入射端后重新选择，灯珠会自动跟随新的入射面。
  6. 开始计算 — 点「开始计算」即可：程序会先自动刷新几何并静默跑一遍结构预检查，再执行仿真（默认 20000 条光线）。先看「快速预览」光路，确认无误后切「精确评估」出定量结论。
  7. 看结果 / 出报告 — 「结果分析」看指标、曲线与出射端面光斑，「报告生成」勾选记录一键出报告。
第一次使用？参数标签旁的 ? 图标鼠标悬停即可看到含义与建议取值（可在顶栏「选项」中开关）。

六、仿真计算

6.1 仿真模式

模式特点适用场景
快速预览秒级出光路，光斑为低样本平滑估计前期方案迭代、看光往哪走
精确评估定量评估，输出完整工程结论，耗时更长定稿评审、出报告
均匀度与达标判定请以「精确评估」结果为准；快速预览只用于看趋势。

6.2 端面设定

自动检测：点「自动检测端面」，软件按面积与朝向自动识别入射端与出射端。

手动拾取：点「拾取→入射端」或「拾取→出射端」进入拾取模式：

操作效果
单击某个面选中该面（自动扩展整个相连的平面 / 曲面区域），替换当前选择
Shift + 单击在当前选择上累加新的面（用于复杂模型多面入射）
再次单击已选中的面取消该面的选择
拖拽旋转视角不会误触发拾取（位移超过 5px 自动忽略）
Esc 或再次点击拾取按钮退出拾取模式

平面与曲面（如穹顶、圆柱侧壁）在相切交界处会自动分割，尖锐边自动阻断，避免「点一个面带走一整片侧壁」。

6.3 多灯珠

点「+ 增加灯珠」可添加多颗灯珠，每颗灯珠独立选择入射面与出射面，已有参数保留不变。状态栏显示「灯珠×N」。

开启「启用 LED 灯珠」后，灯珠沿所选入射面法向自动定位在面前的间隙处，发射方向垂直入射面。

6.4 公差扫参与运行

勾选「公差扫参」会额外自动运行 LED 偏移 0.1 / 0.2 / 0.3 mm 三组仿真，结果用于结果页的公差-亮度衰减曲线。

点「开始计算」后，程序会先自动刷新模型几何（参数化模型重建、导入模型从项目缓存恢复）并静默执行一遍结构预检查（灯珠与导光柱直径匹配、多盘漏光风险等），有预警只在状态栏提示、不阻塞仿真，然后才开始光线追踪。仿真在后台 Worker 中执行，界面不卡；光线较多时进度条按批次平滑推进。

基准评估默认光线数 20000 条（旧项目首次加载会自动升级到该值）。快速预览约 1600 条用于看趋势；需要更精细的均匀性结论时可再调高光线数。

七、结果分析

指标 / 图表含义

均匀性出射端照度分布均匀程度（越接近 1 越好）。按「块聚合照度」计算：先把细网格按约 0.26 mm 聚合为照度块（等效探测器像元积分），剔除杂散块后取最暗块 / 平均块，与肉眼看到的光斑均匀度一致
出射热图出射端面能量分布俯视图，按端面真实长宽比绘制（胶囊形端面画成长条、方形端面画成方形），热点与暗区可直接对应 3D 实物端面位置
轴向分布沿导光柱长度方向的侧壁出光分布

十二、常见问题 FAQ

参数化建模（圆柱 / 锥台输入参数生成）去哪了？

已移除。本工具现在的几何统一来自导入的三维模型，目的是让仿真对象与结构实际设计完全一致，避免「参数化近似」与真实模型之间的偏差。请用 CAD 导出 STL / STEP 后导入。

侧棱镜微齿（SPEOS 式）选项在哪？

已移除。侧壁的齿纹 / 微结构请直接建在三维模型里，导入后按真实几何参与光线追踪；表面粗糙程度则用「表面处理与曲面 → 咬花 / 雾面」控制。

工作区和盘是什么关系？为什么新建的盘是空的？

工作区 = 一个 .lgv.json 文件 = 一个开发人员 / 一个工程；盘 = 工作区内的一个仿真方案。一块盘独立保存自己的模型、材料、灯珠与仿真记录，便于同一工程下横向对比多个方案。新建盘默认为空盘，需要手动导入模型或选择参数化圆柱后才有几何 —— 这样不会出现"没导入却莫名有个圆柱体"的误判。

导入的模型刷新页面后不见了？

约 256KB 以内的网格模型会随项目一起保存在本地，刷新或重新打开后自动恢复。超过该体积的超大模型受浏览器存储限制需重新导入（项目参数与仿真记录始终保留）。建议一次会话内完成仿真与出图，超大模型可分件导入。

出光均匀性和以前的数值不一样了？

均匀性已改为「块聚合照度」口径：按约 0.26 mm 的照度块统计（等效探测器像元积分），并剔除杂散单光线块，结果与肉眼看到的光斑均匀度一致。旧历史记录中的均匀性为旧算法结果，如需前后对比请重新仿真。

X / Y 偏移会不会把导光柱模型也移动？

不会。X / Y 偏移只移动 LED 灯珠本身（沿入射面切线方向），导光柱模型保持原位。这正是模拟「贴片偏位 / 装配公差」的方式。

光线大量在内部反射，出光很少？

按顺序检查：① 材料折射率是否合理（n 越大越「锁光」，PMMA≈1.49）；② 出射端面是否选对；③ 侧面咬花等级是否过低（镜面侧壁会全反射）；④ 查看能量账本，确认能量停在「残留」还是被「吸收」；⑤ 检查 LED 是否与入光面对准（装配间隙与 X / Y 偏移）。

为什么手动拾取入射面后灯珠没有对准？

启用「启用 LED 灯珠」后，灯珠会自动定位在所选入射面法向的间隙处，清除入射端后重新选择也会自动跟随新端面。若仍未对准，请确认模型已成功导入 / 重建（状态栏无报错），并重新选择一次入射面。

想要多个入射面、多颗灯珠怎么操作？

在「仿真计算」点「+ 增加灯珠」，每颗灯珠独立拾取入射面与出射面。同一颗灯珠内可用 Shift+点击 累加多个面。

仿真很慢？

先用「快速预览」迭代方案；需要定量时再切「精确评估」。仿真在后台 Worker 中执行，界面不卡顿。

数据保存在哪里？如何换电脑？

全部数据保存在本机浏览器 localStorage；用 Home 页的「全部导出」备份，「导入文件」还原。请勿使用无痕模式。
